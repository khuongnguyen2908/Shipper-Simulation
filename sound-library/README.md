# Kho tiếng (không đưa vào game)

Tiếng ở đây chỉ để **nghe thử và chọn** trong `?editor` → thẻ 🔊 Âm thanh → mục "Kho tiếng".
Bấm **+ Gắn** thì file được chép sang `src/sounds/` và gắn cho mã đang chọn — chỉ file trong `src/sounds/` mới được gói vào game.

- `kenney/` — các gói của Kenney.nl (CC0: dùng tự do, không bắt buộc ghi tên; xem `kenney/License.txt`).
  Interface Sounds · UI Audio · Impact Sounds · Digital Audio · RPG Audio · Casino Audio · Music Jingles.
- Thêm kho khác: tạo thư mục con mới, bỏ file `.ogg / .mp3 / .wav / .m4a` vào là editor thấy.
